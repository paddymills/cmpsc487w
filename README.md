# Mr. Johnson's Delivery Vehicle Rental

Delivery vehicle rental app for Assignment 2

# Install

```powershell
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python deploy.py
```

# Running

```
flask --app rentals run
```
